# To-Do List App

A lightweight, accessible to-do list web app built with Vite and vanilla JavaScript.

## Features

- Add, edit, complete, and delete tasks
- Filter by **All**, **Active**, and **Completed**
- Clear all completed tasks in one click
- localStorage persistence across refreshes and browser restarts
- Keyboard-friendly controls and validation for blank tasks
- Responsive layout for desktop and mobile

## Setup

```bash
npm install
```

## Run locally

```bash
npm run dev
```

Then open the local URL shown in your terminal.

## Build for production

```bash
npm run build
```

## Preview production build

```bash
npm run preview
```

## Run tests

```bash
npm test
```

## Usage

1. Type a task and select **Add**.
2. Use the checkbox to mark a task complete/incomplete.
3. Select **Edit** to update task text, then **Save** or **Cancel**.
4. Select **Delete** to remove a task.
5. Use filter buttons to switch between all, active, and completed tasks.
6. Select **Clear completed** to remove completed tasks.
