# Security Policy

## Supported versions

This project is currently pre-1.0 and maintained on the default active development branch.

## Reporting a vulnerability

Please do not open public issues for potential vulnerabilities.

Report security concerns privately to the maintainers by opening a private security advisory in GitHub for this repository. Include:

- impact summary
- reproduction steps
- affected files/areas
- any suggested mitigation

We will acknowledge reports and follow up with remediation and disclosure steps as appropriate.
